## 이미지 원칙 (확정)
- **제품·기사 이미지는 불러오거나 저장해 쓰지 않는다.** 출처 표기만으로는 사용 허락이 되지 않는다.
- 대신 **원문 링크를 첨부**한다. 제품마다 본문에 원문 기사 링크, 제조사·디자이너 공식 페이지 링크를 단다.
- 썸네일은 기존처럼 Unsplash(크레딧 표기) 또는 자동 생성 OG 이미지.
- 예외: 제조사 보도자료에 편집 사용 허용 문구가 있거나 사용 허락을 받은 경우에만 실제 사진 사용, 사진 아래 "이미지 제공: ○○ (사용 허락)" 표기.

## 공통 원칙
- 카드뉴스를 그대로 옮기지 않는다. 건마다 배경·맥락·한국 독자에게 의미를 덧붙여 카드뉴스보다 깊게 쓴다.
- 출처 2곳 이상 교차 확인(원천 JSON의 sources 유지 + 필요 시 추가 확인). 원문 직역 인용 금지, 사실과 해석 구분.
- 과거 누적분을 한꺼번에 올리지 않는다. 지난 7일분만 주간 묶음으로.
- 사이트 공통 금지어·문체는 `editorial-guide.md` 7절을 따른다.

## 이번 주 신제품 (반자동)
- 제품 3~5개: 제품명, 무엇이 새로운가, 가격·출시 상태(확인된 것만), 원문 링크.
- "디자이너 코멘트" 자리는 비워 두고 제품별 질문 2~3개를 남긴다(형태, 소재·마감, 구조, 양산성, 사용성).
- 운영자 답변을 받기 전에는 `status: review`로 둔다(자동 발행 대상 아님). 경험·의견을 지어내지 않는다.
