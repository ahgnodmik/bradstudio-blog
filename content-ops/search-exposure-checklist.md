# 검색 노출 점검표 (블로그·네이버·티스토리·영어 공통)

> 2026-11-14 추가. 블라이(blai.co.kr) 가이드의 기능 지도(키워드 선정·포스팅 분석·순위 점검)에서 우리 작업에 적용할 수 있는 원칙만 골라 정리했다.
> 블라이 도구 자체는 쓰지 않는다. 검색량·순위 수치는 직접 확인할 수 없으므로 지어내지 않는다.

## 1. 키워드 고르기 (글 쓰기 전)
- 검색량만 보고 고르지 않는다. 같은 키워드로 최근 발행된 글이 많으면 경쟁이 세다.
- WebSearch로 같은 키워드의 최근 글 수와 상위 글 성격(공식 기관·대형 언론 위주인지)을 먼저 본다.
- 대형 언론·공식 페이지가 상위를 다 차지하면, 구체 상황을 더한 세부 키워드로 좁힌다.
  예: "청년미래적금" → "청년미래적금 2차 계좌 개설 기간"
- 메인 키워드 1개 + 서브 키워드 2~4개를 정한다. 서브 키워드는 연관 검색어·상위 글이 공통으로 쓰는 단어에서 고른다.

## 2. 제목
- 메인 키워드를 제목 앞쪽에 원형 그대로 넣는다. 띄어쓰기도 사람들이 실제로 검색하는 형태를 따른다.
- 자동완성에 뜰 법한 구 조합(키워드 + 신청/방법/기간/조건/뜻/차이)을 우선한다.
- 숫자·날짜·대상을 넣는다. 과장·낚시 표현과 성인·비속어는 쓰지 않는다.

## 3. 본문
- 첫 문단(서론 1~2문장)에 메인 키워드를 자연스럽게 한 번 넣는다.
- 제목에 쓴 핵심 단어는 본문에서도 반복 언급한다. 단, 같은 단어를 문단마다 억지로 넣지 않는다(과다 반복 금지).
- 소제목(■ 또는 h2)에 서브 키워드를 나눠 넣는다.
- 상위 글들이 공통으로 다루는 항목(대상·기간·금액·방법·주의점)은 빠뜨리지 않는다.
- 한 문장 한 뜻, 짧은 문단. 모바일에서 3~4줄 넘는 문단은 나눈다.
- 결론은 행동 유도 문장으로 끝낸다(기존 규칙 유지).

## 4. AI 브리핑·요약 인용 대비
- 질문형 소제목 + 첫 문장에 바로 답(날짜·금액·조건)을 쓰는 Q&A 구조를 쓴다.
- 표로 핵심 수치를 한 번 정리한다.
- 출처는 공식 기관·주요 언론 위주로, 사실마다 2곳 이상(기존 규칙 유지).

## 5. 발행 전 점검
- 금지어(글쓰기 지침 A등급) 0건, 성인·비속어·혐오 표현 0건.
- 법률 리스크: 인물 의혹은 보도 인용으로만, 단정 금지. 보험·금융·건강 단정 금지.
- 분량: 블로그 공백 제외 1,500자 이상, 네이버·티스토리 공백 포함 2,000자 이상, 영어 4,000자 이상.
- 이미지: 블로그 본 글은 규칙대로(신제품은 원문 제품 이미지). 네이버·티스토리·영어 원고는 이미지 없이(2026-10-22 사용자 요청 유지).

## 6. 발행 뒤
- 노출이 약한 글은 같은 글을 복사해 재발행하지 않는다. 제목·첫 문단·소제목을 고쳐 다시 쓰거나, 새 단계 소식이 나오면 새 글로 쓰고 내부 링크로 잇는다.
