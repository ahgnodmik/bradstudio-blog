# 시리즈 지침: 메모와 기록 도구의 역사

> 2026-10-05 확정. 사이트: bradstudio.xyz, 카테고리 `history`(기록의 역사), 시리즈 id `record-history`.
> 회차 목록은 `src/lib/series.ts`. 글 frontmatter에 `series: { id: record-history, order: N }`.

## 방향
인간이 정보를 기록하기 시작한 초기부터 종이, 노트, 타자기, 포스트잇, 컴퓨터·스마트폰 메모까지 기록 도구의 변화를 생활사 관점에서 설명한다. 연도·사건 나열보다 아래 질문 중심.
- 왜 새 기록 도구가 필요했나
- 당시 실제로 어떻게 기록했나
- 이전 방식의 불편함은
- 새 도구가 생활을 어떻게 바꿨나
- 오늘의 메모 습관과 어떤 점이 닮았나

## 작성 원칙
- 각 글은 독립 완결, 15편을 순서대로 읽으면 흐름이 이어지게.
- 한 편 = 중심 질문 하나. 다음 편 내용을 미리 길게 설명하지 않는다(이름 언급 정도만).
- 분량 1,500자 이상, 권장 1,800~2,500자. 반복으로 늘리지 않는다.
- 제목: 정보형. 클릭 유도 문구(충격, 비밀, 반드시, 이것만 알면, 놀라운 n가지) 금지.
- 도입 2~4문단, 익숙한 생활 장면에서 출발 → 역사 배경으로.
- 본문 H2 3~4개(필요 시 H3). 기본 축: 등장 배경 / 당시 사용 모습 / 이전 방식과 차이 / 오늘에 남은 흔적. 글마다 구조를 바꿔 반복 생산 느낌을 피한다.
- EEAT: 생활 관찰형 관점은 사용("노트를 써 보면 알 수 있듯이", "장보기 목록을 떠올리면"). 하지 않은 경험·경력은 꾸며내지 않는다.
- 정확성: 불확실한 연도·수치는 넣지 않는다. 논쟁이 있으면 "일반적으로 알려져 있다", "현재까지 발견된 자료 기준", "여러 지역에서 다른 형태로" 같은 표현.
- 문체: 설명형이되 딱딱하지 않게, 짧은 문장·긴 문장 섞기. 반복 금지 표현: 흥미로운 점은 / 중요한 점은 / 살펴보겠습니다 / 알아보겠습니다 / 결론적으로 / 현대 사회에서. 사이트 공통 금지어(`editorial-guide.md` 7절)도 적용.
- 마무리: 핵심 짧게 정리 → 다음 도구로 자연스럽게 연결. 과도한 내부 링크 유도 금지.
- FAQ 2~3개: 본문 반복 말고 검색자가 실제로 궁금해할 질문.
- sources: 박물관·백과사전·대학 등 확인 가능한 자료를 1개 이상 남긴다.

## 흐름
기록의 탄생(1) → 초기 재료(2~3) → 종이(4~6) → 필기 도구·개인 기록(7~9) → 정보 정리·기계식(10~11) → 간편 메모(12~13) → 디지털(14~15).
15편 마무리: 도구는 바뀌었지만 "기억하고, 전달하고, 다시 찾기 위해"라는 목적은 같다.
