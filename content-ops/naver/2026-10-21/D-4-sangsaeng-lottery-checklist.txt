제목: 상생소비복권 놓치지 않는 체크리스트 20개… 11월 15일 마감 전 꼭 확인

응모권이 안 쌓였다는 사람 대부분은 작은 조건 하나를 놓쳤습니다. 결제 수단, 동의 여부, 결제 장소 중 하나만 어긋나도 실적이 잡히지 않습니다. 시기별로 확인할 항목을 체크리스트로 묶었습니다. 하나씩 표시하며 점검해 보세요.

■ 먼저 숫자 5개만 기억하기
- 11월 15일: 응모·결제 인정 마감
- 3만 원: 응모권 1단위
- 1장 / 2장: 수도권 / 비수도권 3만 원당 응모권
- 30장: 1인 최대 응모권
- 12월: 당첨 통지(초)와 지급(중)

■ 준비 단계 체크리스트
- [ ] 디지털온누리 앱을 설치하고 본인 인증을 마쳤다
- [ ] 앱을 최신 버전으로 업데이트했다
- [ ] 이벤트 참여용 개인정보 제공에 동의했다
- [ ] 앱 알림을 켜 두었다
- [ ] 이번 달 장보기 예산을 먼저 정했다
동의는 11월 15일까지 하면 기간 전체 결제가 인정된다고 보도됐습니다. 미루면 잊기 쉬우니 첫 줄과 셋째 줄은 오늘 끝내세요.

■ 결제 단계 체크리스트
- [ ] 가게가 디지털온누리 가맹점인지 확인했다
- [ ] 실물 가게(오프라인)에서 결제했다
- [ ] 일반 카드가 아니라 디지털온누리 앱으로 결제했다
- [ ] 결제 직후 앱 내역에 기록이 떴다
- [ ] 결제 장소가 수도권인지 비수도권인지 알고 있다
응모 기준은 디지털온누리 결제액입니다. 지난해처럼 신용카드 소비액으로 세지 않습니다. 계산대에서 결제 방법을 말할 때 "온누리로 할게요"라고 먼저 말하면 실수가 줄어듭니다.

■ 응모권 관리 체크리스트
- [ ] 누적 결제액이 3만 원을 넘었다
- [ ] 앱에서 내 응모권 수를 확인했다
- [ ] 30장 상한에 얼마나 남았는지 계산했다
- [ ] 비수도권 결제 실적이 1건 이상 있다
비수도권 결제 실적은 1등 자격과 직결됩니다. 1등 10명은 비수도권 결제로 받은 응모권 보유자 중에서만 뽑습니다. 지방 방문 일정이 있다면 그곳 가맹점에서 장을 보는 것이 유리합니다.

■ 마감 직전 체크리스트(11월 둘째 주)
- [ ] 이벤트 동의가 정상 처리됐는지 다시 확인했다
- [ ] 응모권 현황이 결제 내역과 맞는지 대조했다
- [ ] 결제 취소한 건이 있다면 응모권 변동을 확인했다
결제 취소 시 응모권 처리 방식은 보도로 확인되지 않았습니다. 확인이 필요하면 앱 공지나 고객센터로 문의하세요.

■ 당첨 확인 체크리스트(12월)
- [ ] 12월 초 앱 알림과 공지를 확인했다
- [ ] 당첨금이 디지털 온누리상품권으로 들어왔는지 봤다
- [ ] 받은 상품권을 쓸 가맹점을 정했다
당첨금은 현금이 아닙니다. 가맹점에서 쓰는 상품권이라 사용처를 미리 생각해 두면 좋습니다.

■ 응모권 빠른 계산표
같은 금액이라도 결제 장소에 따라 응모권이 다릅니다. 3만 원 단위로 계산한 예시입니다.
- 3만 원: 수도권 1장 / 비수도권 2장
- 15만 원: 수도권 5장 / 비수도권 10장
- 45만 원: 수도권 15장 / 비수도권 30장(상한 도달)
- 90만 원: 수도권 30장(상한 도달)
비수도권에서는 45만 원이면 상한에 닿습니다. 상한을 넘긴 결제는 응모권이 더 생기지 않으니, 그 이후 지출은 응모권 계산에서 빼고 생각하세요.

■ 이런 경우는 다시 보세요
- 응모권이 0장: 동의 여부와 결제 수단부터 확인
- 생각보다 적게 쌓임: 수도권 결제는 3만 원당 1장인지 확인
- 금액이 3만 원 단위에 못 미침: 남은 금액이 다음 결제와 합쳐지는지 앱에서 확인
- 당첨 문자 수신: 링크를 누르지 말고 앱에서 직접 확인

■ 손해 보지 않는 원칙 3가지
- 응모권 때문에 계획에 없던 지출을 늘리지 않는다
- 당첨금 17억 원은 총액이다, 확률은 참여자 수에 달렸다
- 개인정보나 계좌를 묻는 연락에는 응하지 않는다
세 가지만 지켜도 행사는 '덤'으로 남습니다. 평소 생활비 안에서 결제처만 바꾸는 것이 가장 현명한 참여 방식입니다.

■ 한 장 요약
- 앱 설치 → 이벤트 동의 → 가맹점 앱 결제 → 응모권 확인 → 12월 앱 알림
- 1등 3,000만 원은 비수도권 결제자만
- 2~4등은 전국 대상, 총 5,600명

지금 이 체크리스트를 캡처해 두고, 준비 단계 5칸부터 오늘 안에 채워 보세요.
