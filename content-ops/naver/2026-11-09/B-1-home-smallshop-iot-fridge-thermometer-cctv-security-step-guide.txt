제목: 스마트 냉장고·와이파이 온도계·홈캠, 30분이면 잠근다 — 가정·소상공인 IoT 기기 보안 설정 7단계 (프랑스 혈액원 냉동고 원격 조작 계기)

집이나 가게에 인터넷 연결 기기가 여러 대인데 어디서부터 잠가야 할지 모르겠다면 이 순서대로 따라 해 보세요. 11월 2일(현지시간) 프랑스 국립혈액원(EFS)의 혈장 냉동 보관시설 3곳에서 냉동설비 온도·해동 기준값이 원격으로 크게 올라갔습니다. EFS는 경보가 먼저 울려 혈액제제 손실은 없었다고 밝혔습니다. 침입은 냉장 설비 공급업체 쪽 외부 부품을 거친 것으로 보도됐습니다. 혈액원 같은 기관도 외부 연결 고리 하나로 문이 열렸습니다. 우리 집 스마트 냉장고, 가게 냉장 쇼케이스 온도계, 매장 CCTV도 구조는 비슷합니다. 기기가 인터넷에 붙어 있고, 앱이나 업체가 밖에서 접속합니다.

※ 아래 단계는 일반적인 보안 설정 요령입니다. 모든 공격을 막는다고 보장하지 않습니다.
※ 메뉴 이름과 위치는 제조사·통신사·모델마다 다릅니다. 막히면 설명서나 고객센터를 확인하세요.
※ 이번 사건의 배후와 유럽 마트 냉동고 공격과의 관계는 미확정입니다.

■ 준비물
- 공유기 관리자 페이지 접속 정보(보통 공유기 뒷면 스티커에 있음)
- 각 기기 앱이 깔린 스마트폰
- 메모장 또는 비밀번호 관리 앱
- 30분 정도의 시간

■ 1단계: 연결된 기기 목록 적기 (5분)
먼저 무엇이 연결돼 있는지 압니다. 스마트 냉장고, 에어컨, 로봇청소기, 홈캠, 매장 CCTV 녹화기, 와이파이 온도계, 스마트 플러그를 하나씩 적습니다. 공유기 관리자 페이지의 '연결된 기기' 목록을 함께 보면 빠뜨린 기기가 보입니다. 이름을 모르는 기기가 있으면 표시해 둡니다. 가게라면 냉장 쇼케이스, 포스(POS) 단말, 출입 관리기도 적습니다. 목록이 있어야 다음 단계에서 빠짐없이 점검할 수 있습니다.

■ 2단계: 공유기부터 잠그기 (5분)
공유기는 집과 가게 전체의 현관문입니다.
- 관리자 비밀번호를 기본값에서 바꿉니다. 와이파이 비밀번호와 다른 것으로 정합니다.
- 와이파이 암호화 방식을 WPA2 이상으로 맞춥니다. 메뉴에 WPA3가 있으면 그것을 고릅니다.
- 외부에서 공유기 관리 화면에 접속하는 기능(원격 관리)은 쓰지 않으면 끕니다.
- UPnP 기능은 기기가 스스로 외부 접속 통로를 여는 기능입니다. 꼭 필요한 기기가 없다면 끄는 쪽을 검토합니다.
- 공유기 펌웨어 업데이트를 확인합니다. 통신사 임대 공유기라면 고객센터에 최신 여부를 물어봅니다.

■ 3단계: 기기마다 기본 비밀번호 바꾸기 (5분)
같은 모델이 같은 초기 비밀번호로 출고되는 경우가 있습니다. 초기 비밀번호는 설명서에 적혀 있어 누구나 찾을 수 있습니다. 홈캠과 CCTV 녹화기는 특히 먼저 바꿉니다.
- 기기마다 다른 비밀번호를 씁니다.
- 숫자만 쓰지 말고 영문, 숫자, 기호를 섞습니다.
- 바꾼 비밀번호는 비밀번호 관리 앱에 저장합니다.
- 가게라면 직원 공용 계정 대신 사람별 계정을 만들 수 있는지 확인합니다.

■ 4단계: 앱 계정에 2단계 인증 켜기 (5분)
스마트 냉장고나 홈캠은 제조사 앱 계정으로 원격 조작됩니다. 기기 비밀번호를 바꿔도 앱 계정이 털리면 소용이 없습니다.
- 앱 계정 설정에서 2단계 인증(문자·인증 앱)을 켭니다.
- 다른 사이트와 같은 비밀번호를 쓰고 있었다면 지금 바꿉니다.
- 가족이나 직원과 계정을 공유한다면, 앱의 '구성원 초대' 기능으로 각자 계정을 쓰게 합니다.
- 퇴사한 직원, 이사 간 세입자의 접근 권한이 남아 있는지 확인하고 지웁니다.

■ 5단계: 업데이트와 지원 기간 확인 (5분)
프랑스 사례에서도, 지난달 유럽 마트 사례에서도 문제는 외부 부품과 오래된 원격 제어 장치 쪽에서 나왔습니다.
- 각 앱에서 기기 펌웨어 업데이트를 확인하고 설치합니다.
- 자동 업데이트 옵션이 있으면 켭니다.
- 제조사 홈페이지에서 해당 모델의 보안 업데이트가 아직 나오는지 봅니다. 몇 년째 업데이트가 없다면 교체 시기를 고민합니다.
- 새로 살 때는 한국인터넷진흥원(KISA) IoT 보안인증 표시가 있는지 확인하는 것도 방법입니다.

■ 6단계: 필요 없는 원격 기능 끄기 (3분)
원격 기능이 많을수록 들어올 문도 많아집니다.
- 밖에서 냉장고 온도를 바꿀 일이 없다면 원격 제어는 끄고 알림만 남깁니다.
- 쓰지 않는 홈캠은 앱에서 비활성화하거나 전원을 뽑습니다.
- 가게 냉장 설비를 업체가 원격 관리한다면, 접속이 필요할 때만 열어 두는 방식이 가능한지 물어봅니다.
- 손님용 와이파이와 업무용 기기 와이파이를 나눕니다. 공유기의 '게스트 네트워크' 기능을 쓰면 됩니다.

■ 7단계: 이상 알림 받는 습관 만들기 (2분)
EFS가 피해를 막은 것은 경보가 제때 울렸기 때문입니다. 가정과 가게도 같습니다.
- 냉장고·온도계 앱에서 온도 이상 알림을 켭니다. 가게라면 사장님과 담당 직원 둘 다 받게 합니다.
- 알림이 실제로 오는지 문을 잠깐 열어 두는 식으로 한 번 시험합니다.
- 홈캠·CCTV 앱의 '새 기기 로그인' 알림을 켭니다.
- 모르는 로그인 알림이 오면 비밀번호를 바로 바꾸고 모든 기기에서 로그아웃합니다.
- 가게라면 아침 개점 때 냉장 설비 표시 온도를 눈으로 한 번 보는 습관을 들입니다. 앱 숫자와 실제 표시가 다르면 업체에 연락합니다.

■ 버리거나 팔 때
중고로 팔거나 버리는 기기는 공장 초기화를 합니다. 앱에서 기기 등록도 해제합니다. 등록이 남아 있으면 새 주인의 영상이나 정보가 내 앱에 보일 수 있고, 반대도 생길 수 있습니다.

■ 아직 확인되지 않은 것
- 프랑스 혈액원 공격의 배후: 미확정
- 쿨월드가 말한 제3자 부품의 제조사와 취약점 내용: 공개되지 않음
- 110도 설정 시도: 르카나르 앙셰네 보도를 여러 매체가 인용, EFS 공식 확인은 아님
- 국내 가정·매장 기기에서 같은 수법 피해: 이번 취재 범위에서 확인되지 않음

■ 오늘 할 일
오늘 저녁 30분을 잡고 1단계 목록부터 적어 보세요. 시간이 부족하면 2단계 공유기 관리자 비밀번호와 3단계 홈캠·CCTV 비밀번호, 이 두 가지만 바꿔도 출발점이 됩니다. 가게를 운영한다면 내일 아침 냉장 설비 업체에 "원격 접속이 켜져 있는지, 비밀번호를 언제 바꿨는지" 문자 한 통을 보내 두세요.
