제목: 집에서 AI 에이전트용 PC를 24시간 켜 두려면? 용도 정하기·전력·네트워크·원격 접속·보안·점검까지 7단계 준비 가이드 (499달러 Lapis One 공개 계기)

AI 에이전트를 집 컴퓨터에 켜 두고 싶은데 무엇부터 준비해야 할지 막막한 분이 많습니다. 미국 스타트업 Pamir가 2026년 9월 에이전트 상시 구동용 미니PC Lapis One을 공개하면서 이 질문이 다시 늘었습니다. 사전 주문가는 499달러입니다. 하지만 전용 기기를 사기 전에 집 환경부터 갖추는 게 순서입니다. 남는 노트북이든 새 미니PC든 같은 7단계를 거치면 됩니다.

※ Lapis One의 배송 일정은 자료끼리 엇갈려 확인 필요입니다. 한국 정식 출시는 미확정입니다. 아래 단계는 특정 제품과 상관없이 쓸 수 있는 일반 준비 순서입니다.

■ 1단계. 에이전트가 어디서 '생각'하는지 먼저 확인하기
에이전트 구조는 크게 두 가지입니다.
- 클라우드형: AI 연산은 OpenAI·Anthropic 같은 외부 모델 서비스가 하고, 집 컴퓨터는 지시를 받아 파일을 고치고 프로그램을 실행합니다.
- 로컬형: AI 모델 자체를 집 컴퓨터 안에서 돌립니다.

클라우드형이면 저사양 기기로도 충분한 경우가 많습니다. Lapis One이 Rockchip RK3576 칩과 8GB 메모리라는 낮은 사양을 고른 것도 이 구조를 전제로 합니다. 로컬형이면 메모리와 그래픽 성능이 훨씬 많이 필요합니다. 쓰려는 에이전트의 설명서에서 '필요한 API 키'와 '권장 메모리' 항목을 먼저 찾아보세요.

■ 2단계. 하드웨어 후보 정하기
선택지는 네 가지로 좁혀집니다.
- 집에 남는 노트북이나 데스크톱
- 라즈베리파이 같은 싱글보드 컴퓨터
- 인텔·AMD 기반 미니PC나 맥 미니
- Lapis One 같은 에이전트 전용 기기

처음이라면 남는 기기로 시작하세요. 일주일만 돌려 봐도 내게 필요한 성능이 보입니다. 전용 기기의 장점은 원격 접속 같은 기능이 미리 묶여 있다는 점입니다. Lapis One은 원격 접속 도구 Tailscale을 기본으로 넣었다고 Yanko Design과 제조사 자료가 전했습니다.

■ 3단계. 전력과 설치 위치 정하기
24시간 켜 둘 기기는 놓는 자리가 중요합니다.
- 통풍이 되는 곳에 두기. 책장 안쪽이나 이불 옆은 피하기
- 멀티탭은 과부하 보호 기능이 있는 제품 쓰기
- 전력 측정 플러그로 하루 사용량 재 보기
- 정전 뒤 자동으로 켜지는지 BIOS나 설정에서 확인하기

노트북을 쓴다면 배터리를 계속 100%로 충전하는 상태가 됩니다. 제조사가 충전 한도 설정을 제공하면 켜 두세요. 소음이 신경 쓰이면 침실과 떨어진 곳에 두세요.

■ 4단계. 네트워크 안정화하기
에이전트는 외부 AI 서비스와 계속 통신합니다. 연결이 끊기면 작업도 멈춥니다.
- 가능하면 무선 대신 유선 랜으로 공유기에 연결하기
- 공유기 설정에서 이 기기에 고정 IP(DHCP 예약) 주기
- 공유기 펌웨어를 최신으로 올리기

고정 IP를 주면 나중에 집 안에서 접속할 주소가 바뀌지 않습니다.

■ 5단계. 원격 접속 설정하기
밖에서 에이전트 상태를 보려면 원격 접속이 필요합니다. 방법은 두 갈래입니다.
- VPN형 도구(Tailscale 등): 내 기기끼리만 사설망으로 묶어 줍니다. 공유기 포트를 열 필요가 없어 초보자에게 편합니다.
- 포트 포워딩: 공유기 포트를 외부에 엽니다. 설정이 잘못되면 외부 공격에 노출되기 쉬워 권하지 않습니다.

SSH로 접속한다면 비밀번호 대신 키 방식으로 로그인하도록 바꾸세요. 휴대폰에서도 접속되는지 집 와이파이를 끄고 한 번 시험해 보세요.

■ 6단계. 보안 울타리 치기
에이전트는 내 계정 권한으로 움직입니다. 실수나 오작동이 그대로 내 계정에 남습니다.
- 에이전트 전용 사용자 계정을 따로 만들기
- 메일·클라우드 드라이브는 꼭 필요한 권한만 주기
- AI 서비스 API 키에 월 사용 한도 걸기
- 결제, 송금, 메일 발송처럼 되돌리기 어려운 작업은 사람 승인 단계를 남기기
- 운영체제 자동 보안 업데이트 켜기

Lapis One의 Agent KVM처럼 다른 컴퓨터 화면을 보고 조작하는 기능을 쓴다면 더 조심해야 합니다. 연결된 PC에 로그인된 모든 서비스가 에이전트 손에 닿습니다. 처음에는 중요한 계정이 없는 PC에서만 시험하세요.

■ 7단계. 일주일 시험 운전과 점검표
설정이 끝나면 바로 중요한 일을 맡기지 마세요. 일주일 동안 가벼운 작업만 돌리며 기록합니다.
- 하루 전력 사용량
- 소음과 발열
- 연결 끊김 횟수
- API 사용 요금
- 에이전트가 한 일의 로그

일주일 기록을 보고 성능이 모자라면 그때 하드웨어를 바꿉니다. 전용 기기를 살지도 이 기록으로 판단하면 됩니다.

■ Lapis One을 고려한다면 알아 둘 숫자
- 사전 주문가 499달러, 정가 599달러(여러 매체·판매 페이지 일치)
- 359달러, 879.99달러 표기는 확인 필요
- 2차 물량 2026년 12월 31일, 3차 물량 2027년 2월 28일 예상이라는 보도가 있으나 10월 첫 물량이라는 앞선 보도와 엇갈려 확인 필요
- 배송 국가가 미국·EU·영국·캐나다로 한정됐다는 보도는 한 곳에서만 확인돼 확인 필요

■ 지금 해 볼 것
오늘 저녁 집에 남는 노트북 한 대를 공유기 옆에 유선으로 연결해 두세요. 전력 측정 플러그를 꽂고 쓰려는 에이전트를 일주일만 켜 둡니다. 다음 주 이맘때 전력·소음·끊김 기록을 보고 전용 기기가 정말 필요한지 결정하세요.
