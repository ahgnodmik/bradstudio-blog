제목: 올겨울 월동 준비 체크리스트 40개, 슈퍼 엘니뇨 '포근한 겨울' 예보에도 빼면 안 되는 것

[ ] 표시를 하나씩 지우면서 보세요. 올겨울은 엘니뇨가 역대급으로 커지는 가운데 맞는 겨울입니다. 평균은 포근할 수 있어도 짧고 매운 한파와 잦은 눈·비가 함께 거론됩니다. 그래서 체크리스트도 '추위'와 '습한 날씨' 두 축으로 짰습니다. 출력하거나 캡처해서 쓰기 좋게 영역별로 나눴습니다.

■ 왜 지금 준비하나 (30초 요약)
- 동태평양 허리케인 시즌이 누적 사이클론 에너지(ACE) 기준 관측 사상 최대를 기록했습니다(폭스웨더·CBS뉴스).
- 세계기상기구(WMO)는 10~12월 엘니뇨 감시 해역 수온이 평년보다 약 3.7도 높을 것으로 전망했습니다. 정점은 12월 무렵, 지속은 2027년 2월까지로 봤습니다.
- 기상청은 9월 23일 전망에서 11월 기온은 높고 강수는 많은 쪽으로 봤습니다. 찬 공기가 일시적으로 내려와 기온이 크게 떨어질 때가 있다는 단서도 달았습니다.
- 다음 기상청 3개월 전망은 10월 23일에 나옵니다.

■ 날씨 정보 챙기기 (5개)
- [ ] 10월 23일 기상청 3개월 전망 확인
- [ ] 11월 하순 12월~내년 2월 전망 확인
- [ ] 휴대폰 날씨 앱에 한파·대설 특보 알림 켜기
- [ ] 출퇴근 전 체감온도 보는 습관 만들기
- [ ] 부모님 댁 지역 날씨도 즐겨찾기에 추가

■ 수도·동파 (7개)
- [ ] 수도 계량기 위치 확인
- [ ] 계량기함 안을 헌 옷이나 보온재로 채우기
- [ ] 노출 배관에 보온재 감기
- [ ] 베란다 세탁기 급수·배수 호스 점검
- [ ] 외부 수도꼭지 물 빼고 잠그기
- [ ] 한파 예보 때 장기 외출 시 수돗물 가늘게 틀어 두기
- [ ] 관리사무소·수도사업소 연락처 저장

■ 난방·보일러 (6개)
- [ ] 보일러 시운전으로 온수·난방 확인
- [ ] 찬 방이 있으면 배관 공기빼기
- [ ] 연통 연결부 이탈·부식 여부 눈으로 확인
- [ ] 일산화탄소 경보기 작동 확인
- [ ] 전기히터·전기장판 전선 피복 상태 확인
- [ ] 멀티탭 하나에 난방기기 여러 개 꽂지 않기

■ 단열·실내 (6개)
- [ ] 창문·현관 틈 문풍지 붙이기
- [ ] 북쪽 창에 단열 시트 붙이기
- [ ] 두꺼운 커튼 달기
- [ ] 찬 바닥에 러그나 매트 깔기
- [ ] 가습기 세척하고 꺼내 두기
- [ ] 결로 생기는 벽·창 주변 환기 계획 세우기

■ 자동차 (8개)

- [ ] 타이어 마모 상태와 공기압 확인
- [ ] 냉각수(부동액) 양과 농도 확인
- [ ] 겨울용 워셔액으로 교체
- [ ] 줄 생기는 와이퍼 교체
- [ ] 성에 제거 도구, 장갑, 담요 트렁크에 넣기
- [ ] 눈 많은 지역 운행 잦으면 겨울용 타이어·체인 검토
- [ ] 지하 주차장이 없다면 앞유리 덮개 준비

- [ ] 우산과 방수 신발 현관에 두기(눈·비 잦은 날 대비)

- [ ] 실내 온도 기준 정하기(18~20도 안팎)
- [ ] 지난겨울 난방비 고지서 찾아 사용량 메모
- [ ] 정부·지자체 난방비 지원 대상인지 주민센터에서 확인
- [ ] 수입 식재료 가격 흐름 살피기(엘니뇨는 세계 작황 변수)

■ 많이 놓치는 함정 3가지
- '포근한 겨울' 예보는 평균 이야기입니다. 강한 한파가 며칠 오는 것만으로도 계량기는 얼 수 있습니다.
- 눈이 습할수록 무겁습니다. 비닐하우스, 차양, 약한 지붕은 눈 쌓임에 취약합니다.
- 보일러를 완전히 껐다가 다시 데우면 오히려 연료가 더 들 수 있습니다. 외출 모드를 쓰세요.

■ 날짜별 실행표

- 10월 말~11월 초: 단열·실내 6개
