제목: [고정] 피그마 상세페이지 폼 세팅해 드립니다, 한 번 세팅하면 다음 장은 사장님이 직접

상세페이지 한 장 맡길 때마다 30만 원, 일주일. 신상품이 나올 때마다 이 과정을 반복하고 계신가요?
저는 상세페이지를 대신 그려 드리지 않습니다. 사장님이 사진과 글만 바꿔 넣으면 완성되는 피그마 틀을 만들어 드립니다.

■ 1. 무엇을 받으시나요
- 860px 상세페이지 피그마 파일 1개
- 섹션 템플릿 8~10개: 메인 후킹, 문제 제기, 제품 소개, 특장점 3개, 사용법, 비교표, 리뷰, 배송·교환 안내, 마지막 구매 유도
- 브랜드 컬러·폰트 변수: 색 하나 바꾸면 페이지 전체가 같이 바뀝니다
- 오토레이아웃 적용: 글이 길어지면 박스가 알아서 늘어납니다
- 섹션 순서는 드래그로 바꾸기만 하면 됩니다

■ 2. 카피는 GPT에 맡기세요
상세페이지 문구까지 외주로 쓰면 비용이 두 배가 됩니다. 문구는 제품을 제일 잘 아는 사장님이 쓰는 게 맞습니다.
섹션마다 GPT에 넣을 프롬프트를 같이 드립니다. 제품 정보 다섯 줄만 붙여 넣으면 후킹 문구, 특장점 문장, 자주 묻는 질문 초안이 나옵니다. 사장님은 고르고 다듬기만 하세요.

■ 3. 상품과 가격
- 셀프 템플릿: 피그마 파일 공유 링크 + 사용 매뉴얼 PDF / 20,000원 / 결제 즉시
- 기본 세팅: 섹션 8~10개 템플릿 + 컬러·폰트 변수 / [가격]원 / [기간]일
- 브랜드 세팅: 기본 + 기존 상세페이지 3장을 템플릿으로 전환 / [가격]원 / [기간]일
- 세팅 + GPT 팩: 기본 + 섹션별 카피 프롬프트와 작성 예시 / [가격]원 / [기간]일
- 사용법 교육: 화면 공유 60분, 직접 1장 만들어 보기 / [가격]원

■ 먼저 2만 원으로 써 보세요
세팅 의뢰가 부담되면 셀프 템플릿부터 시작하세요. 이 글에서 말한 섹션 10개가 들어간 피그마 파일을 복제 링크로 드리고, 사진·글 바꾸는 법과 GPT 프롬프트를 PDF 매뉴얼로 정리해 드립니다. 써 보시고 우리 브랜드에 맞춘 세팅이 필요하면 그때 의뢰하셔도 됩니다. 템플릿 비용은 세팅 의뢰 시 차감해 드립니다.

■ 4. 이런 분께 맞습니다
- 신상품이 한 달에 2개 이상 나오는 스마트스토어·쿠팡 판매자
- 디자이너 없이 직원이 상세페이지를 고치는 브랜드
- 상세페이지마다 톤이 달라 브랜드가 흩어져 보이는 곳

■ 5. 이런 분께는 안 맞습니다
- 한 장만 필요하고 다시 고칠 일이 없는 경우: 일반 상세페이지 외주가 더 저렴합니다
- 피그마를 전혀 열어 볼 생각이 없는 경우: 교육 상품을 같이 권해 드립니다

■ 6. 진행 순서
1. 문의: 상품 링크와 참고하고 싶은 상세페이지 1~2개 보내기
2. 견적: 섹션 구성안과 일정 회신(1일 이내)
3. 세팅: 중간 공유 1회, 수정 2회 포함
4. 전달: 피그마 파일 소유권 이전 + 사용 설명 영상
